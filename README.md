# MindCare 🧠
AI-Powered Cognitive Games & Memory Assistance

MindCare is a student project designed to support elderly people experiencing dementia-related memory difficulties, with a focus on North Eastern Region (NER) of India.

## Features
- Six cognitive games
- AI-based game difficulty suggestions
- Family photo recognition games
- Daily activities and reminders
- Player performance dashboard
- Caregiver support and reports
- Multilingual accessibility
- Planned offline PWA support

## Cognitive Games
1. Remember the Sequence
2. Family Recognition
3. Find the Target
4. Quick Match
5. Change the Rule
6. Arrange the Day

## Technology Stack
- React.js
- Phaser.js
- Next.js
- FastAPI
- PostgreSQL
- Python
- i18next

## AI Game Suggestion Engine
- Score >= 80%: Suggest next level
- Score 30–79%: Suggest current level
- Score < 30%: Suggest easier level

Players can accept or ignore suggestions.
